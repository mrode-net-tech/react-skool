# Writing course text

## Lesson content

- A lesson is about 60 minutes of work for a senior PHP developer who is new to React.
- Lessons explain and set tasks. Code examples show the idea with another domain or a smaller case, and the learner writes the solution to the task.
- Acceptance criteria are concrete checks that a review can tick off.
- PHP comparisons appear where the mental model is similar, and they say where it differs.
- Every new API links to its official docs.

## Style

Write plain English at B1/B2 level, with short sentences and concrete facts: what the code does, which command to run, what the output is. Use "is", "has" and "does". Name a real source or leave the claim out. Use as many list items as there really are. End a section when its content ends.

Formatting: sentence-case headings, bold only where it helps the reader, straight quotes, few em dashes, plain list items.

These are the signs of AI writing from Wikipedia's list. Grep for them before you finish, and rewrite every hit:

- words: delve, crucial, pivotal, key (as an adjective), robust, seamless, leverage, showcase, highlight, enhance, foster, underscore, testament, tapestry, landscape, vibrant, intricate, meticulous, additionally, essential, powerful, game-changing
- phrases: "serves as", "stands as", "boasts", "plays a vital role", "it's worth noting", "in this lesson we will explore"
- structures: "not only X but also Y", "not X, but Y", "it's not just X, it's Y", a trailing "-ing" comment ("..., ensuring that ..."), vague attribution ("experts say"), a summary at the end of a section
- formatting: Title Case headings, bullets of the form "**Label**: text", emoji
